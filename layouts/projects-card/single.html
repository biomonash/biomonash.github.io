Project Timeline

{{ if $isStKilda }}
Stage 1: Hardware & Tough Encasement Deployment of rugged breakwater housings, Song Meter recorders, and sustainable autonomous power systems (SAPS).
Stage 2: Software Integration & Audio Pipeline On-device audio preprocessing, Mel-spectrogram generation on Raspberry Pi, and latency testing.
Stage 3: AI Inference & Real-Time Classification Completing the MVP AI model to separate overlapping calls and generate activity heatmaps.
{{ else }}
Stage 1: Visualisation Phase (MVP) Excel to PostgreSQL data migration, interactive filterable map view, and species explorer.
Stage 2: Integration Phase Data uploading workflows (Excel, API, web forms), online image tagging, and media management.
Stage 3: Community Science & Automated Reporting Public observation uploads, educational features, and automated council report generation.
{{ end }}
{{ if $isStKilda }}
Durable Systems

Tough Encasement + Stable Internals: Designing a system to withstand harsh breakwater marine conditions using weighted matrix factors.

Electronic Systems

Signal Processing + Sustainable SAPS: Creating microphone, radio, and sustainable autonomous power components with custom circuit boards.

Software Integration

Embedded Systems + Digital Ecosystems: Audio preprocessing and Mel-spectrogram generation directly on Raspberry Pi with RAM and latency tuning.

Machine Learning

AI Model Building + Deployment: Training models to count overlapping Little Penguin calls in real-time non-invasively.

{{ else }}
Frontend UI & Map View

Interactive, filterable species map and explorer built with React, TypeScript, Vite, TailwindCSS, and Leaflet.

Backend & PostGIS Data Pipeline

High-performance stateless Go API with pgx + sqlc querying a PostgreSQL database with PostGIS for spatial coordinates.

Automated Reporting Generator

Direct graph and summary generation powered by Nivo charts, eliminating manual Excel spreadsheet handling for council staff.

Bioacoustic Multimedia Integration

Spectrogram visualisation using Arbimon workflows and BirdNet audio recognition for species verification.

{{ end }}
